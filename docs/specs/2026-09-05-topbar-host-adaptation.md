# 顶部功能按钮的宿主适配

## 已确认要求

普通网页与桌面保留相同功能，顶部按钮统一控件尺寸、图标大小、间距和垂直中心线。宿主差异只决定窗口控件所需的外侧安全留白。

2026-09-05 在 45120 内置浏览器的 981 × 964 视口核实以下入口：

| 入口 | 当前行为 | 布局要求 |
|---|---|---|
| 打开 / 收起侧边栏 | 驱动官方左侧导航开关 | 保留原动作及折叠状态 |
| 新建会话 | 左栏收起时打开现有新建菜单；展开时保留官方新会话入口 | 不因网页适配而删减入口 |
| 展开 / 折叠底部面板 | better-sidebar 的底部面板开关 | 保留原动作 |
| 折叠 / 展开侧边栏 | better-sidebar 的右侧工作台开关 | 保留原动作，与左侧独立 |
| 新建标签页 + | 工作台的现有标签菜单 | 保留入口与菜单行为 |

活动插件页另外提供的对话开关继续按既有条件显示，参与同一组几何布局。

## 实现范围

- 仅修改中枢 `plugins/omnimux/src/client` 的现有顶部布局计算与局部样式，不更换事件处理器或创建第二套按钮。
- 使用宿主已有的 `data-dsh-desktop-mode` / `data-dsh-desktop-platform` 标记。实际 macOS 桌面保留 84px 窗口控件安全区；普通网页使用 8px 外边距。不用浏览器 UA、平台推断或新环境服务。
- 顶部操作按钮为 32 × 32px，SVG 为 16 × 16px，组内间距 8px，圆角 8px。使用原生 `--dsw-*` 色彩及交互 token。
- 左右操作按钮及标签新增按钮共享垂直中心线。工作台标签为实际右侧按钮组让位，不能在增加控件尺寸后遮挡标签。
- 保留侧栏展开 / 收起、窄视口下的可操作性和现有菜单关闭行为。

## 验收

1. 单测覆盖无宿主标记、macOS 桌面及其他桌面平台的留白分支，验证同一 DOM 在宿主标记就绪后重新计算。
2. 回归左侧开关转发、左栏收起的新会话菜单定位、右侧和底部状态独立性、标签新增入口保留。
3. 浏览器记录五个入口的矩形、可点击性、图标尺寸和中心线；覆盖侧栏展开 / 收起及窄视口，保留前后截图。
4. 45120 与实际桌面宿主证据分别记录，不以网页模拟的桌面属性替代真实桌面验收。操作已有服务前遵循开发环境物化限制。
