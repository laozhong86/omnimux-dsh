## 一、 产品定位与核心目标

### 1.1 产品定位
面向社媒多渠道矩阵运营、短剧/图文出海团队及创作者的**全渠道内容发布表现与受众互动分析中枢**。通过聚合各社媒平台（TikTok、X/Twitter、YouTube、Instagram 等）的数据表现，辅助运营团队评估内容策略、发现爆款规律、优化发布频次与发布排期。

### 1.2 核心业务价值
- **多平台矩阵总览**：打通多渠道跨平台数据孤岛，集中掌握各矩阵账号的发帖量、粉丝演进、点赞与播放表现。
- **爆款规律与策略洞察**：通过 7×24h 最佳发布时间热力图、内容生命周期衰减曲线、发帖频次与互动率关联模型，反哺选题创作与发布节奏。
- **发布效果量化评估**：提供单帖表现排行榜与平台明细汇总，精准归因每个渠道的 ROI 与互动黏性。

## 三、 功能需求清单与交互规范 (按优先级划分)

### 📌 P0（核心必做 / MVP 范围）

#### 1. 全局筛选与调度控制
- **双 Tab 页面架构**：
  - `发布效果分析`（默认主视图）：聚焦内容发布、传播与受众互动。
  - `私信互动分析`：聚焦粉丝咨询量、首次响应时效（TTR）与会话转化。
- **多维级联筛选器**：
  - **平台筛选**：支持“全部平台”及各已绑定平台（如 `TikTok (12篇)`、`X / Twitter`、`YouTube`、`Instagram`）。
  - **账号矩阵筛选**：支持“全部账号矩阵”或指定具体 Profile / 账号分组。
  - **发布来源筛选**：区分“手动发布 (Manual)”与“OmniMux 自动同步”。
  - **时间跨度筛选**：支持快捷时间段（`近 7 天`、`近 30 天`、`近 90 天`）。
- **即时增量同步调度机**：
  - 展示文案：`上次同步：X分钟前 · 下次调度：Y分钟后`。
  - 点击 `立即同步` 按钮：触发后台即时拉取外部平台最新数据，并在 800ms 内平滑更新大盘指标。

#### 2. 核心 5 大 KPI 概览卡片
| KPI 指标 | 展示格式 | 业务口径 / 计算说明 | 辅助标签 |
| :--- | :--- | :--- | :--- |
| **综合互动率 (ER)** | `2.26%` | $\frac{\sum(\text{Likes} + \text{Comments} + \text{Shares} + \text{Saves})}{\sum \text{Views}} \times 100\%$ | - |
| **总触达人数 (Reach)**| `1.9K` / `0` | 所选周期内内容触达的独立去重受众数 (UV) | - |
| **总粉丝量 (Followers)**| `635` | 绑定的全矩阵累计粉丝总数 | `↗ 近30天 +17` 绿标 |
| **本周期发帖量 (Posts)**| `12` | 所选周期内发布的有效帖子总量 | `↗ 正常更新` 绿标 |
| **最佳表现单篇 (Best Post)**| 缩略图 + `930 播放量` | 综合互动率与播放量加权得分最高的内容 | `查看详情 ↗` 直达入口 |

#### 3. 基础走势与分布图表 (2×2 栅格)
- **各平台发帖分布 (Posts per platform)**：柱状图展示各平台的发帖篇数占比。
- **发帖频次时间走势 (Posts over time)**：柱状图展示各自然周/日的发帖节奏变化。
- **各平台获赞分布 (Likes per platform)**：柱状图展示各平台的累计点赞量。
- **点赞时间累积走势 (Likes over time)**：柱状图展示点赞随时间的分布趋势。

#### 4. 复合多维互动走势大盘 (Engagement Over Time)
- **多折线联动展示**：支持主/次双 Y 轴（绝对量数值 vs 互动百分比）。
- **9 项指标即时勾选交互**：
  - `点赞数 (Likes)`（默认勾选，红线）
  - `评论数 (Comments)`（默认勾选，蓝线）
  - `分享数 (Shares)`（默认勾选，绿线）
  - `收藏数 (Saves)`（默认未勾选，橙线）
  - `播放/浏览 (Views)`（默认勾选，紫线，次 Y 轴）
  - `曝光量 (Impressions)`（默认未勾选，青线）
  - `触达人数 (Reach)`（默认未勾选，灰线）
  - `链接点击 (Clicks)`（默认未勾选，粉线）
  - `互动率 (Eng. Rate)`（默认勾选，绿虚线）
- 用户在底部勾选/取消勾选对应指标时，折线图实时响应，零延迟重绘。

#### 5. 聚合与明细表格
- **各平台表现明细汇总表 (Platform Breakdown)**：
  - 列项：`平台`、`发帖数`、`点赞`、`评论`、`分享`、`收藏`、`点击`、`播放/浏览`、`曝光`、`触达`、`互动率 (ER)`。
  - 支持各列点击升降序排序；部分平台不支持的字段统一显示 `-` 保底。
- **爆款内容表现排行榜 (Top Performing Posts)**：
  - 展示具体内容标题、发布时间戳、封面图、各互动明细指标（赞、评、转、藏、播放量、引流涨粉、ER）。
  - 支持按 ER 或播放量降序展示，帮助运营快速定位优质爆款素材。

### 📌 P1（深度洞察与策略增强）

#### 1. 最佳发布时间 5 级绿度热力图 (Best Time to Post)
- **7×24 小时时间网格**：
  - 纵轴：周一至周日（`周一` ~ `周日`）。
  - 横轴：24 小时时段（`0点` ~ `23点`）。
- **五分位数色阶 (5-Level Green Shades)**：
  - 级别 0（无数据/极低）：`#ebedf0`
  - 级别 1（轻度活跃）：`#9be9a8`
  - 级别 2（中度活跃）：`#40c463`
  - 级别 3（高度活跃）：`#30a14e`
  - 级别 4（最优峰值）：`#216e39`
- **悬停与推荐提炼**：
  - 格点 Hover 展示具体时段互动指数 Tooltip。
  - 底部自动提炼 Top 3 最优时段推荐 Chips（如 `周日 10:00 · 互动指数 24`、`周三 20:00 · 互动指数 18`）。

#### 2. 粉丝增长演进曲线 (Follower Evolution)
- 多平台折线对比图：时间轴上展示 TikTok、X 等矩阵账号的历史粉丝增长轨迹，Hover 展示当日各平台细分与总粉丝量。

#### 3. 策略分析模型
- **发帖频次与互动率关联模型 (Posting Frequency vs Engagement)**：
  - 分析每周发帖篇数（如 `6-10篇/周` vs `11+篇/周`）对互动率的影响，提炼最优发布节奏建议（如 `TikTok 11+篇/周 · 互动率 2.2%`）。
- **内容生命周期互动衰减曲线 (Engagement Accumulation)**：
  - 分析一条内容发布后在不同时间窗口（`发布时`、`0-6小时`、`6-12小时`、`12-24小时`、`1-2天`、`2-7天`、`7-30天`）累积互动的百分比分布。
  - 自动标注关键里程碑：`半数互动在发布后 2-7天内产生`、`80% 互动集中在 2-7天长尾期`。

## 四、 异常处理与状态机规范

1. **空状态 (Empty State)**：
   - 未绑定任何账号：展示空态占位图并提供 `前往账号中心绑定` 引导按钮。
   - 所选周期无发帖：KPI 显示 0，图表展示空网格骨架，提示“所选周期内暂无发布数据”。
2. **账号授权过期或异常**：
   - 在筛选器对应账号后标注黄色预警图标 `⚠ 授权已过期`，提示用户前往重新授权。
3. **字段缺失兼容**：
   - 针对部分平台不提供某些字段（如 Twitter 无 Saves、部分接口无 Reach/Views），表格与卡片统一显示 `-`，不得出现 `NaN`、`undefined` 或页面坍缩。
4. **网络与接口重试**：
   - 接口 5xx/401 失败时，保留上一次成功渲染的大盘快照，并弹出非阻塞 Toast 提示重试。
