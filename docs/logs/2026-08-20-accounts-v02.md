## 改动

- **T01 Host 元数据层**：`src/official/account-meta.js`（`createAccountMetaStore`：read/update/remove/prune + 纯函数 `mergeMeta`；`$DSH_HOME/omnimux/accounts.json`，0700/0600/整文档重写，坏 JSON 归空）；`public-account.js` 白名单加 `expires_at/connected_at`、新增 `computeStatus`（站点 status 归一 / expires_at 驱动 / 默认 active）、`pickAccountsView` overlay 合并；`http-routes.js` body 解析修为 POST+PATCH、新增 `PATCH /omnimux/accounts/{id}`（`{group?, agent_usable?}`，非法值 400、空串 group 清除、站点行缺失仍可更新纯元数据）、GET 合并 overlay + 懒清理、DELETE 清 overlay；`src/index.js` 注入 metaStore。测试：`account-meta.test.js` 新增，`public-account.test.js` / `http-routes.test.js` 扩展（含非本地 origin PATCH 403、真实文件 store 端到端）。
- **T02 前端底座**（`plugins/omnimux-accounts/src/client/`）：`api.js` 增 `patchAccount`；`platforms.js`（supported tiktok/instagram/youtube + coming x/小红书/抖音/facebook/视频号，官方色字面量）；`styles.js`（`.omnimux-accounts-*` 前缀 CSS 字符串 + 幂等 `<style>` 注入，esbuild 无 CSS 输出路径故不走 CSS Module）；`view.js` 纯函数（filter/sort/summarize/relativeTime/uniqueValues/presentStatuses/fmt/localeText）+ `view.test.js`；`locales.js` zh/en 全量扩充（原 14 key 保留）。
- **T03 卡片网格**：`use-accounts.js`（phase/accounts/error/busy + refresh/patch 乐观回滚/disconnect，401→need-login）；`chips.jsx`（StatusDot 四色/PlatformChip 官方色/GroupChip/Avatar 首字母兜底）；`OverviewBar`（4 数字卡可点筛选 + CTA）；`FilterBar`（搜索/平台/分组/状态/排序，选项数据派生）；`AccountCard`（状态点+Agent 开关+⋯ 菜单确认断开）；`AccountsSection` 重做（骨架屏/错误条/空态占位）。

- 状态仍 unproven：keyless 测试通过，未对真实 OmniMux 账号列表宣称可用。
