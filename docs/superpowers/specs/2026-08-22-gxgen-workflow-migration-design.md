# 设计规格：Gxgen 工作流 → OmniMux 完整迁移

- 日期：2026-08-22
- 状态：已获方向拍板（顺序 + 项目语义 + 落盘路径）；Phase 0 文件格式字段待实现前冻结
- 契约真源（进度矩阵）：[`docs/contracts/gxgen-workflow-migration.md`](../../contracts/gxgen-workflow-migration.md)

## 1. 问题

要把 Gxgen 工作流能力迁入 OmniMux，但若继续只在「画布 workspace」层打磨，会与产品期望的「项目壳」脱节；且「项目 / dsh 工作区 / 画布工作区」三者易被代理混用，导致越做越偏。

## 2. 目标

1. **完整迁移** Gxgen 工作流能力到 OmniMux 插件体系。  
2. **先做项目壳**，再完善单项目主界面 UI/交互，再做多项目/模板。  
3. 用代理可读的蓝图 + 进度矩阵，保证任意新会话能接手最新进度与规范。

## 3. 已拍板决策

| 决策点 | 选择 | 理由 |
|---|---|---|
| 推进顺序 | 项目壳 → 单画布主界面 → 多项目/模板 | 用户明确指令 |
| 「项目」语义 | **一个本地作品文件夹 = dsh 工作区 = 会话 cwd**，不是画布 `WorkspaceStore`，也不是父 cwd 里藏 json | 2026-08-23 改拍板（对齐 MiniMax + dsh 会话必须绑工作区） |
| 侧栏 | 「新建项目」与「新建会话」同级；另加「项目库」 | 产品入口 |
| 新建副作用 | 弹名称窗 → 默认库建文件夹 → `workspaces.create({ path })` → `sessions.create({ workspaceId })` → 画布 3:7 | 2026-08-23 改拍板；禁止 `connectWorkspace` |
| 落盘路径 | `<videos>/OmniMux/Projects/<可读名>/` | 对齐 MiniMax 视频已知文件夹；不再跟当前会话 cwd |
| 蓝图落点 | 产品树 `docs/contracts/` 为进度真源；本文件为设计规格 | 新会话强制可读 |
| Phase 0 代码归属 | 先写进 `omnimux-workflow`，回头再拆 | 用户拍板；插件内用 `src/projects/` 预留边界 |
| **侧栏结构** | 「工作流」→「项目库」；新建项目 + 项目库与新建会话同级 | 用户拍板（结构性调整） |
| **页面结构** | 项目库 = 入口页（项目列表）；点项目 = 详情页（会话 + 右侧画布 tab） | 用户拍板 |
| **画布落位（已拍板）** | C 挂 `dsh-better-sidebar` 画布 tab（按会话与 Files 隔离；官方 details 不接管） | 用户 2026-08-22 晚改拍板；宽拖来自面板宿主不是 DETAILS_MAX |
| **入口页范围** | 只留核心（新建/本地项目 tab/搜索/排序/卡片）；砍查看教程/共创项目 | 用户拍板 |
| **画布落位时机（二次拍板）** | 右侧画布**前移到 Phase 0**（不再全屏过渡）；点新项目 = 中间会话（小）+ 右侧画布（大） | 用户拍板 2026-08-22；源码已确认 `details` 可 priority=-10 shadow、`conversation`/`details` 并列列可并存 |
| **侧栏「新项目」落位** | 并排「新会话」（非其下 rank 行）；hub `sidebar-coordinator` 扩展「并排按钮」注册 | 用户拍板 2026-08-22；coordinator 为 hub 自有代码可改 |
## 4. 方案取舍（摘要）

| 方案 | 内容 | 结论 |
|---|---|---|
| A 画布 workspace 换皮当项目 | 最快，但语义错误 | **否决** |
| B `$DSH_HOME` 全局项目库 | 跨文件夹统一，但与「跟工作区文件夹走」冲突 | **否决**（本次） |
| C 工作区文件夹内 `.omnimux/projects/` + 会话绑定 | 旧 Phase 0；多项目挤同一 cwd，Finder 看不见作品 | **2026-08-23 否决（主路径）** |
| D 默认库独立文件夹 = 工作区 | `<videos>/OmniMux/Projects/<名>/` 同时是作品包和 dsh cwd | **采纳**（规格 `2026-08-23-omnimux-local-project.md`） |

## 5. 范围

### Phase 0 必须

- 侧栏新建项目（并排「新会话」）/ 项目库  
- 本地项目文件 CRUD（最小）  
- 新建 → 会话绑定  
- 打开项目 → 可进画布最短路径  
- **右侧画布**：`dsh-better-sidebar` 画布 tab；项目会话关空 Files；普通会话保持 Files；中间会话（小）+ 右侧画布（大）并存

### Phase 1 必须

- L2–L7 单项目主界面 UI/交互与 Gxgen 同步（详见契约分层）  

### Phase 2

- 多画布库、模板、变体等  

### 非目标

- Timeline / 导出 / 文字轨 / 积分 / 云分享公链（契约裁剪表）
