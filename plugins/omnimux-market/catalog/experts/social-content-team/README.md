# 社媒多模态内容创作工坊 (Multimodal Social Content Studio)

工业级全链路社交媒体多模态内容创作专家团，涵盖**爆款文案、口播解说配音、视觉概念生图、视频分镜生成、BGM卡点配乐与后期剪辑合成**，全面对齐 MiniMax Design 工业级多模态创作架构，并深度打通 OmniMux 工作流画布与剪辑工坊。

## 类型

Team 型（7 人全模态工坊团队）

## 核心能力矩阵

- **爆款文案与钩子策划**：小红书情绪种草、抖音黄金3秒口播台词、广告投放 A/B 测试文案变体；
- **口播解说与声音工程**：多角色旁白生成、自然微停顿（`<#0.5#>`）、音色克隆与人声分离；
- **视觉生图与主体立绘**：Lock/Open 留白起草、角色设定全身图（`character-ref-guard` 契约）、动态海报设计；
- **分镜视频原生生成**：一工具一镜头原则、推拉摇移运镜控制、动作密度平衡、首帧质量严审；
- **情绪配乐与节拍卡点**：纯器乐 BGM 生成、Intro/Drop/Outro 结构编曲、鼓点节奏卡点；
- **后期剪辑与音画合成**：音画同步校验（$|\Delta| \le 0.08\text{s}$）、BGM 自动避让（-14dB）、转场 xfade，并支持直接调用 `omnimux-clip` 剪辑工坊多轨时间线。

## 核心内化契约（Contracts）

1. **`anti-loop.md`**：同参数失败 3 次强制熔断并向用户求助；
2. **`character-ref-guard.md`**：角色参考图四铁律（性别明确、完整全身图、纯人物无道具、排除随机配饰）；
3. **`editing-defaults.md`**：音画同步偏差 $|\Delta| \le 0.08\text{s}$ 硬红线、BGM 避让 -12~-18dB；
4. **`canvas-discipline.md`**：资产全量回写画布节点，复杂任务自动分组（Group Node）；
5. **`output-format.md`**：结构化媒体路径、参数表格与质检清单。

- "为我的美妆品牌写一篇小红书种草文案，并生成一组商业摄影级别的产品海报"
- "把这篇解说文案转为 3 段分镜视频与旁白，混合轻快音乐后在剪辑工坊中打开"
