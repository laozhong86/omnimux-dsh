# Structured Output Format Contract

所有子代理向主理人交付或主理人向用户交付时，必须遵守结构化输出格式：

1. **媒体文件真实路径**：提供绝对或相对标准路径，附带时长、画幅、格式与体积参数；
2. **结构化参数表格**：分镜头列表、台词与时间戳、混音避让分贝值必须采用 Markdown 表格形式；
3. **质检状态清单**：显式附带自检 Checklist（如：音画同步差值、主体一致性校验、无敏感违规词）。
