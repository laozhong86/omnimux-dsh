# Character Reference Guard — 角色与主体参考图四铁律

> image-agent 在生成任何"人物参考图 / 角色设定 / 产品主体参考 / character sheet / casting reference"前，必须严格遵守以下 4 条铁律：

## 铁律 1：性别与主体特征不明确时必须询问
用户描述未明确性别（如"骑行者"、"咖啡师"、"运动员"）时，严禁 AI 自作主张默认性别，必须向主理人确认。

## 铁律 2：立绘必须是完整全身图
- **头顶与脚底**：头顶上方有呼吸留白，双脚与鞋底完整可见，严禁在膝盖或脚踝处裁切；
- **构图占比**：主体占画面高 70%~85%，推荐使用 3:4 竖版比例。

## 铁律 3：纯主体，不堆砌无关道具与杂乱环境
- 角色立绘核心是锁定面部与服装特征，背景默认纯色或白底；
- 不主动添加未要求的自行车、乐器等复杂物件（避免分散注意力与生成畸变）。

## 铁律 4：排除 AI 随机生成的杂乱配饰
- 主动规避模型容易凭空脑补的多余项链、护腕、色带与奇异头巾。
