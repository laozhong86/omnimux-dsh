# 结算

来源：https://www.tiktokdramacenter.com/help-center/detail/6a0ed443124e9404bb0a1fa3 （2026-08-13 13:38）

## 前置

先过企业认证，再交【企业合作】→【企业认证】→【企业注册】和【付款账户】。

- 供应商「文件类型」交政府或税务机关签发的公司注册文件，并填文件编号
- 银行信息必须准，否则打款失败
- 认证 / 合同 / 供应商 / 收款四个主体一致
- 银行所在地仅：加拿大、中国、日本、新加坡、美国、香港

## 账单日（两处原文不一致）

- 操作手册：每月 20 日前生成账单
- 本页：每月结束前生成上一月账单

以【结算管理】→【账户收益】→【待结算】页上的账单为准。没有可结算金额显示【暂无打款】。每次有 PDF 和 Excel 两版，先下载核对。

打款时效两边一致：发票提交并过审后 **5 个工作日内平台执行打款**。打款 ≠ 到账。

未配打款信息，或勾选金额未到最低额（原文只写 USD $，未给数字），不能上传发票。

## 抬头

向 **TikTok Pte. Ltd.** 开票，不要开大陆增值税发票。

- 国家：Singapore
- 税号：201719908M
- 地址：1 Raffles Quay, #26-10, Singapore 048583.

用 Word/Excel 按模板做标准发票，导出 PDF（< 10 MB）。

必须满足：金额 = 结算总额；组织名 = 合同组织名；发票日期晚于结算完成日且不能是未来日。

发票字段：TT entity name/address/Tax info；Merchant entity name/address/Tax info（如适用）；Invoice Number；Invoice Date；Settlement Amount Period；Settlement Amount Description；Settlement Amount。

## 上传

【结算管理】→【账户收益】→【待结算】勾条目 → 页底提交发票。状态去【已发起结算】看，历史打款也在这。

| 状态 | 含义 |
|---|---|
| 发票审核中 | 等 |
| 发票审核未通过 | 回账户收益重选结算单，重传发票 |
| 付款处理中 | 发票过了，平台在打 |
| 打款成功 | 平台已发起打款 |
| 打款失败 | 见下 |

打款失败三种修法：

1. 付款信息被删：回【付款账户】补银行信息，再在账户收益重选结算单
2. 付款信息还在审：等过审，再重选结算单
3. 信息有误被银行退回：条目右侧 `>` → 发票详细信息 →【更新打款详情】；【付款账户】查看→编辑，过审后再重选结算单

Q&A：银行填错需等银行退回，状态变 【Unable to make payment】，改对后点 【try again】。
