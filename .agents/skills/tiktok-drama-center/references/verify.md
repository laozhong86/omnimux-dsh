# 企业主体认证

来源：https://www.tiktokdramacenter.com/help-center/detail/6a0ed419cdee5b04e989024c （2026-08-13 13:37）

上传、签约、结算都强制先过这一步。必须用**超级管理员**登。一机构多主体时，每个签约主体单独认证。

## 四类材料

电子提交。格式 JPEG / PNG / PDF / JPG，单文件 ≤ 10 MB，最小 480×480。彩色原件扫描，四角完整，无裁切、折痕、第三方水印、模糊。有效期至少还剩 30 天。

### 1. 营业执照 / 业务认证

政府签发。必须同时有：当地语言法定全称、英文全称、企业注册号、地址、法人姓名。

可接受：营业执照、公司注册/登记证书、商业登记摘录、税务登记证。

缺字段就多份合成一个 PDF。常见补法：执照 + 登记证书；执照 + 同主体银行开户/存款证明（补英文名）；执照 + 第三方正规翻译件（附翻译机构资质或公章）。

香港：不满一年 NNC1，满一年 NAR1。

列表没有该公司注册国：找 TikTok 运营申请加国家。

### 2. 代表人带照片身份证明

政府签发。必须有：签发国家/地区、完整法定姓名、证件号、国籍或完整地址至少一项（文件上要有 Nationality 或 Address）、出生日期。

可接受：驾照、护照、永居卡、州/省级身份证。缺国籍/地址时优先护照。身份证正反面合成一个 PDF（反面常有有效期）。不要黑白复印件。

### 3. 授权证明

证明该人是主要代表人（法律/财务/行政上可代表公司，通常是法定代表人、董事、总经理）。

企业材料里已有代表人姓名：同一文件可再传一次。没有姓名：另传能同时显示代表人姓名和公司名的注册书/税务书。新加坡常补近一年 Bizfile。以上都没有才单独出代表人授权书。

### 4. 地址证明

首次非必须；审核可能要求补。建议与身份证件不是同一份。须有：签发机构、代表人全名、地址、签发或声明日期，且日期在最近 6 个月内。

可接受：驾照或永居卡、水电账单、银行/信用卡账单、租约、房产税、保险单、政府信函、雇主信、工资单、抵押贷款声明。

## 线上两段

【企业认证】→【认证新企业】

1. 企业信息：资质文件、当地语言名称、英语名称、注册编号、国家/地区、省/州、城市、街道门牌、执照有效期（无有效期勾「长期有效」）。填写地址必须和文件一致。
2. 代表人信息：证件、全名（按文件语言）、出生日期、证件号、证件有效期、国籍或地址、地址证明（建议填）、代表人证明。

## 审核

提交不等于通过。官方 1 到 3 个工作日。通过才算完成。

不通过：点【修改】只改正失败项再交。常见原因：缺字段、文件类型不对、图像质量、注册号不一致、执照过期、只有当地语言没有英文名。

要补地址证明：在法人/代表人段补文件再交。

自查后仍误伤，或超过 3 个工作日无反馈：点客服申诉。

多份材料进同一上传口：合并成一个 PDF。
