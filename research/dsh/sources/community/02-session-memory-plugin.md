## [![Image 2](https://avatars.githubusercontent.com/u/264861249?s=64&v=4) Spirtxiaoqi7](https://github.com/Spirtxiaoqi7)[Aug 13, 2026](https://github.com/deepseek-ai/deepseek-harness/discussions/516#discussion-10609174)

I built a tree-out community plugin that adds editable, session-isolated personalization memory to DeepSeek Harness without patching Harness source.

Repository: [https://github.com/Spirtxiaoqi7/mindspace-dsh-session-memory](https://github.com/Spirtxiaoqi7/mindspace-dsh-session-memory)

 Release: [https://github.com/Spirtxiaoqi7/mindspace-dsh-session-memory/releases/tag/v0.1.0](https://github.com/Spirtxiaoqi7/mindspace-dsh-session-memory/releases/tag/v0.1.0)

 Topics: `dsh-plugin`, `memory`, `agent-memory`, `session-memory`

## What it contributes

*   Direct preview of the current DSH compaction summary, plus an optional user override.
*   Editable preferences, user facts, and instructions for the assistant.
*   Per-session relationship identity, conversation mission, and optional roleplay preset.
*   Model-facing `get_session_memory` and `update_session_memory` tools.
*   Conservative extraction from explicit user statements only.
*   Conflict replacement by stable item id with append-only session-event history.
*   One optional role/purpose/style question on the first empty turn.

## Composition

The installable package declares one `dsh.bundle` layer and one dual-face package-root row. The Host face owns the event-sourced service, projection, prompt contribution, tools, extraction hook, and generated Typert descriptor. The Web face self-mounts its generated Remote contribution and registers a Personalization / Memory Center settings section. It does not modify `api-remotes`, built-in bundles, root tsconfigs, or other Harness packages.

## Verification

*   Fresh-clone `pnpm install --frozen-lockfile`, build, tests, and pack pass on Node 24.
*   GitHub CI passes with the same sequence.
*   The release tarball installs into an isolated profile.
*   The package root and Typert artifact import from the installed profile.
*   An isolated Web profile starts on an alternate port; `/` and the plugin client bundle both return 200.
*   Downloaded release asset SHA-256 matches the locally accepted tarball: `a9954200e2ca0fa0096058d1de27bfc6053189d98a528987de377ebd0c2aa084`.

The initial compatibility target is the public `0.1.0-rc` family. Feedback is especially welcome on long-term stable seams for tree-out Typert contributions, client Remote self-mounting, and session-event namespace governance.

## 中文补充说明

这是一个面向 DeepSeek Harness 的**通用会话记忆治理插件**，并非只服务于角色扮演。目标是让每个会话都能被赋予独立用途，同时让用户和 Agent 对长期上下文拥有可见、可修改、可覆盖的控制权。

当前记忆按会话隔离，主要包括：

1.   DSH 原始压缩摘要的直接预览与可选人工覆盖；
2.   用户偏好和明确提供的个人信息；
3.   用户对 AI 的长期要求，例如“不要编造测试结果”；
4.   当前会话的关系身份与窗口使命，例如编程搭档、导师、朋友或可选扮演关系；
5.   可独立启停的会话级扮演预设。

Agent 获得 `get_session_memory` 和 `update_session_memory` 两个入口。新的明确事实可以按稳定条目 id 覆盖旧冲突信息，修改仍以追加事件的方式保留审计历史。自动抽取只处理用户明确表达的信息，不推断敏感属性。

安装已发布的预构建包：

undefinedshell
dsh plugin --profile web add https://github.com/Spirtxiaoqi7/mindspace-dsh-session-memory/releases/download/v0.1.0/mindspace-dsh-session-memory-0.1.0.tgz
dsh web
undefined

希望向维护者重点确认三点：

*   树外插件长期使用 `session-memory/*` 事件命名和版本迁移时，官方推荐的治理方式；
*   生成式 Typert contribution 对树外插件是否有计划中的稳定接口；
*   Web 插件自行调用 `remote.$mount(...)` 是否是推荐方式，或未来是否会提供正式聚合扩展点。

欢迎维护者和社区用户直接试用、提出兼容性意见或指出应拆成更通用 Host API 的部分。

## Update / 我们更新了：v0.2.0

The plugin has been upgraded from editable memory to a governed, session-scoped V2 layer:

*   confirmed user facts and AI observations are separated in a 300-character profile;
*   preferences and assistant requirements are consolidated into at most three categorized cards each;
*   corrections replace conflicts with stable card ids;
*   complete-state extraction uses an atom coverage ledger and rejects partial writes atomically;
*   append/merge/replace/skip activity is visible with evidence and before/after values;
*   V1 replay now repairs duplicate fallback categories instead of blocking future writes;
*   assistant names and nicknames have a dedicated relationship/roleplay identity path and cannot pollute the user profile;
*   session isolation and restart persistence were verified against the running Web profile.

Two V2 UI screenshots and the implementation/contribution notes are now in the README:

[https://github.com/Spirtxiaoqi7/mindspace-dsh-session-memory](https://github.com/Spirtxiaoqi7/mindspace-dsh-session-memory)

Release and prebuilt package:

[https://github.com/Spirtxiaoqi7/mindspace-dsh-session-memory/releases/tag/v0.2.0](https://github.com/Spirtxiaoqi7/mindspace-dsh-session-memory/releases/tag/v0.2.0)

Validation: 13 automated tests plus real model write, merge, conflict replacement, legacy repair, cross-session isolation, and restart recovery.
