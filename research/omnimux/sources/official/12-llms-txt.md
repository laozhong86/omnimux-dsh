# OmniMux (omnimux.ai)

> All-in-one social media API for AI agents. One API to create and orchestrate content across platforms. Pay per call, no subscription.

OmniMux (operated at omnimux.ai) is the all-in-one social media API for AI agents. It is not a human-first scheduling dashboard. Keep Claude, ChatGPT, Codex, Cursor, or any MCP-compatible agent as the operator; OmniMux supplies the hands: content creation, multi-platform orchestration, metering, routing, and platform execution across global channels—through one API, CLI, Skill, and MCP.

## What OmniMux is (and is not)

- **Is:** all-in-one social media API so AI agents can create content and orchestrate multi-platform distribution with unified auth, metering, and audit logs
- **Is:** delivery via REST API, CLI, Agent Skill, and MCP
- **Is not:** a replacement for your agent or an opaque end-to-end “auto content factory” that removes human/agent steering
- **Is not:** product support claims for mainland China domestic platforms in the public channel matrix
- **Billing:** free to install; pay per call / pay per invocation with per-action credit prices and per-key spend caps; **no subscription required** (see pricing)
