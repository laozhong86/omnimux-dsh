## 📌 TL;DR（执行摘要）

- **核心目标**：深度对齐 MiniMax Design 最佳实践，在 OmniMux 工作流画布中打造一套心智清晰、交互丝滑、完全符合 DSH 原生 UI 规范的资产管理抽屉。
- **核心心智架构**：
  1. **【画布】Tab（当前创作态）**：聚焦当前画布运行态素材，专属提供搜索、三维下拉筛选（`类型 ∨`、`标签 ∨`、`时间 ∨`）、列表/网格切换、Hover 元数据卡片、`⌖` 靶心定位以及 13 项全量专属右键菜单。底部为单个高对比度主按钮 **`[↑ 导入文件]`**。
  2. **【资产】Tab（全局持久态）**：聚焦工程持久化资产与主体库，置顶展示「主体库」成套资产入口，下接项目物理目录树（如 `1111` 文件夹）、文件列表、空态拖拽上传区，底部提供 **`[📁 新建文件夹]` + `[↑ 导入文件]`** 双操作栏。
- **底层架构关键决策**：
  - 下拉筛选与上下文菜单采用 **Fixed Portal 绝对坐标挂载机制**，彻底解决侧边栏 `overflow: hidden` 导致的浮层截断与现代浏览器 Popover API 命名冲突；
  - 所有图标 100% 遵循 DSH / Lucide 统一的 **1.6px 细线条线性矢量规范（Line Outline）**，彻底杜绝黑色块与实心斑点；
  - 深度复用画布现有 `AssetsDrawer`、`ContextMenu`、`HeaderControls`、`lucide-react` 与 `--wb-*` 主题 Token 基础设施，严禁重复造轮子。

### 2.2 【画布】Tab 详细交互规格

1. **三维筛选 Popover 规范（100% 像素级对齐原型）**：
   - **`[类型 ∨]`**：激活时按钮呈白框高亮；下拉菜单宽 140px，包含「全部、图片、视频、音频、文本、其他」6 项，左侧为白底圆圈加黑勾复选框（`type-check-circle`）。
   - **`[标签 ∨]`**：激活时按钮呈白框高亮；下拉菜单宽 136px，包含 7 种创作标签，左侧配 10px 实心彩色圆点（人物 `#f87171`、场景 `#fb923c`、待定版 `#facc15`、最终版 `#4ade80`、道具 `#38bdf8`、音色 `#c084fc`、服装 `#818cf8`）。
   - **`[时间 ∨]`**：激活时按钮呈白框高亮；下拉菜单宽 145px，采用两段式布局：
     - 第一组（排序）：`最新优先`（带白勾）、`最旧优先`；
     - 分割线（`1px #27272a`）；
     - 第二组（时间范围）：`全部`（带白勾）、`今天`、`近 7 天`、`近 30 天`、`自定义`。
2. **Flyout 预览详情卡片（Hover Inspector）**：
   - 鼠标悬停列表项或网格项 150ms 触发，在侧边栏右侧精确悬浮展开（宽 250px）；
   - 展示：高清缩略图、文件名、右上角 `⌖` 快速定位按钮、尺寸、格式、大小、修改时间、底部「查看上下游依赖链路」入口。
3. **`⌖` 靶心定位与画布联动**：
   - 悬停列表项时在右侧浮现 `⌖` 图标；
   - 点击后，画布视口自动以平滑动画（`smooth`）将目标节点居中，并触发 2 次蓝色脉冲光晕（`highlight-pulse`）。
4. **【画布 Tab】专属右键菜单（13 项全量功能）**：
   - 宽度 232px，深黑毛玻璃浮层，全量 1.6px 细线条线性矢量图标，包含：
     1. `+ 添加到画布`（快捷键：`⌘ ⇧ A`，直接投入画布当前视口中心）
     2. `💬 添加到对话`（一键在 Agent 输入框挂载 `@资产: 文件名` 标签）
     3. `✦ 添加到主体库`（提取素材特征录入主体库）
     4. `📥 存到项目资产`（将画布素材持久化落盘至 `/assets` 目录）
     5. `⌖ 在画布中定位`（居中聚焦目标节点）
     6. `↗ 打开`（快捷键：`⌘ O`，大图/原文件全屏预览）
     7. `📁 在 Finder 中打开`（快捷键：`⌘ ⇧ R`，联动系统访达）
     8. `📋 复制路径`（写入系统剪贴板）
     9. `📄 复制文件`（快捷键：`⌘ C`）
     10. `📑 复制副本`（快捷键：`⌘ D`，原地生成 `-副本` 资产）
     11. `☷ 切换到树形视图`
     12. `✎ 重命名`（快捷键：`Enter`）
     13. `🗑 删除`（快捷键：`Backspace`，红色危险态 `#f87171`）
5. **底部操作栏**：
   - 单个白底黑字高对比度主按钮 **`[↑ 导入文件]`**（高 36px，圆角 8px），点击唤起原生文件选择器，批量向画布注入素材节点。

### 2.3 【资产】Tab 详细交互规格

1. **置顶主体库卡片**：
   - 卡片高度 48px，左侧包含紫色主体图标 + `主体库 ⓘ`，右侧带 `>` 箭头，点击无缝切换至主体库二级管理页。
2. **专属右键菜单体系**：
   - **素材文件右键（5 项）**：`🖼 添加到画布`、`💬 添加到 agent`、`📁 在 Finder 中打开`、`🗂 移动到`、`🗑 删除`（红字）。
   - **文件夹右键（4 项）**：`📁 在 Finder 中打开`、`✎ 重命名`、`🗂 移动到`、`🗑 删除`（红字）。
3. **空态拖拽区**：
   - 虚线边框拖拽区，支持操作系统文件拖入，释放后自动增量导入并生成缩略图。
4. **底部操作栏**：
   - 双胶囊按钮：`[📁 新建文件夹]`（次级深色底）+ `[↑ 导入文件]`（主级白色底）。

---

### 2.4 主体库二级页面规格

1. **顶部操作**：`[← 返回]` 回退至资产 Tab，右侧带 `[最近更新 ∨]` 排序下拉（包含「最近更新 ✓」与「使用次数」两项）。
2. **分类 Filter Chips**：五联胶囊（`所有类型`、`角色`、`场景`、`风格包`、`自定义`），点击即时筛选。
3. **主体成套卡片**：展示成套主体缩略图、名称、包含资产数，支持直接拖拽成套投入画布。
4. **底部操作**：`[创建主体]`（主按钮）+ `[导入主体包]`（次按钮）。
